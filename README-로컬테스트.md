# 오늘운세365 로컬 테스트

## 로컬 서버 실행

프로젝트 폴더에서 PowerShell 또는 명령 프롬프트를 열고 아래를 실행하세요.

```powershell
cd "C:\Users\user\Desktop\오늘의 운세"
python -m http.server 8000
```

`python` 명령을 찾을 수 없으면 다음 명령을 사용하세요.

```powershell
py -m http.server 8000
```

또는 프로젝트 폴더의 `start-server.bat`을 실행해도 됩니다. 서버가 켜진 터미널 창은 테스트가 끝날 때까지 열어두세요.

브라우저에서 [http://localhost:8000](http://localhost:8000)을 여세요. 서버를 종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.

## 브라우저 테스트 체크리스트

- [ ] 첫 화면과 오늘 날짜가 표시된다.
- [ ] 이름, 생년월일을 입력하고 성별을 선택할 수 있다.
- [ ] 각 항목을 비운 상태에서 제출하면 입력 안내가 표시된다.
- [ ] 정보를 입력하고 **오늘의 운세 보기**를 누르면 결과가 나온다.
- [ ] 생년월일과 날짜에 따라 12개 운세 세트 중 해당 결과가 표시된다.
- [ ] 종합운, 재물운, 애정운, 직장·사업운, 건강운, 대인관계운의 내용과 별점이 표시된다.
- [ ] 행운 숫자, 행운 색상, 행운 방향, 오늘의 한마디가 표시된다.
- [ ] **운세 결과 복사**를 눌러 안내 메시지를 확인하고, 붙여넣기로 복사된 내용을 확인한다.
- [ ] **운세 공유하기**를 눌러 공유 창이 뜨는지 확인한다. 취소한 경우에도 오류가 나지 않아야 한다.
- [ ] 공유 API 미지원 브라우저/환경에서 공유를 누르면 결과가 클립보드에 복사되고 대체 안내가 표시된다. (공유 API 지원 환경에서는 DevTools에서 `navigator.share`를 임시로 제거한 뒤 새로고침하여 대체 동작을 확인할 수 있다.)
- [ ] **다시 운세 보기**를 누르면 결과가 숨겨지고 입력 화면으로 돌아가며 기존 입력값은 유지된다.
- [ ] 개발자 도구의 Device Toolbar로 모바일 폭을 확인한다. 버튼이 화면을 넘지 않고 세로로 배치되어야 한다.

## JavaScript 오류 확인

브라우저에서 `F12`를 눌러 개발자 도구를 열고 **Console** 탭을 선택한 뒤 페이지를 새로고침하며 위 항목을 확인하세요. 빨간색 오류가 표시되면 오류 메시지와 줄 번호를 확인하고, **Sources** 탭에서 `script.js`의 해당 위치를 살펴보세요. 복사/공유 기능은 브라우저 권한 또는 보안 컨텍스트에 따라 클립보드 동작이 달라질 수 있으니 화면 안내 메시지도 함께 확인하세요.
